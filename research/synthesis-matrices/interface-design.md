# Interface design synthesis matrix

Baseline: 23 ranked hashes, 20 distinct names.

Evidence labels: `frontend-design`, `canvas-design`, `slack-gif-creator`, `algorithmic-art`, `ui-ux-pro-max`, `web-design-guidelines`, `minimalist-ui`, `industrial-brutalist-ui`, `redesign-existing-projects`, `design-taste-frontend`, `gpt-taste`, `high-end-visual-design`, `tailwind-patterns`, `ckm:ui-styling`, `ckm:design-system`, `image-to-code`, `ckm:design`, `brandkit`, `mobile-design`, `ckm:brand`.

| Decision area | Retained synthesis | Conflict resolution or added safeguard |
| --- | --- | --- |
| Creative direction | Select an audience-, job-, and emotion-specific visual thesis | Minimal, maximal, brutalist, and premium guidance become contextual profiles, not universal mandates |
| Existing products | Audit evidence and preserve effective conventions before restyling | Novelty does not outrank product memory or an authoritative design system |
| Systems | Use semantic tokens and behavioral component contracts | Reuse is required only where behavior or appearance actually repeats |
| Visual artifacts | Build logos, brand boards, banners, GIFs, canvas work, and algorithmic art from a medium-aware concept and visual system | References contribute relationships and constraints, not permission to copy protected expression |
| Image-to-code | Infer structure, responsiveness, and assets separately | A screenshot proves one state only; accessibility and platform behavior can justify documented deviations |
| Mobile | Account for touch, reachability, safe areas, keyboards, and dynamic text | Platform norms outrank desktop-derived visual fidelity |
| Quality | Render and inspect responsive, edge, interaction, and accessibility states | Automated linting is a floor, not visual proof |
| Omission repair | Added performance, focus, reduced-motion, and honest-verification gates | Popular aesthetic advice alone did not adequately cover production risk |

Resulting modes: new design, audit/redesign, brand/design-system, visual artifacts, image-to-code/mobile, and implementation QA.
