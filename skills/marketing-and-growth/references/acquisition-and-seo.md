# Acquisition and SEO

## Select channels from the buying path

Choose channels based on where the target audience discovers, evaluates, and buys—not from a generic channel checklist. Connect every campaign to a specific offer, landing experience, conversion event, economics, and attribution limitation.

For paid or outbound work, define audience, intent, promise, proof, format constraints, budget, frequency, and stop conditions. Generate variants around distinct hypotheses such as problem frame, proof, offer, or objection. Never fabricate testimonials, scarcity, endorsements, or performance claims.

## Build search value

Map search intent to a useful page and a business-relevant next step. Technical search work should cover discoverability, indexability, canonicals, redirects, internal links, rendering, performance, structured data, and validation against current search-engine guidance.

Content should answer the query with original utility and verifiable claims. Avoid keyword stuffing, imitation expertise, or schema that describes content the page does not contain.

## Programmatic pages

Create pages at scale only when each page can provide material, differentiated value from reliable data. Define the query pattern, data source, template invariants, quality threshold, duplication controls, crawl budget, index policy, monitoring, and retirement rule. A large keyword set is not by itself a reason to publish pages.

## Measure honestly

Separate leading indicators from business outcomes. State attribution windows, incrementality limits, and costs. Evaluate quality downstream—qualified demand, activation, retained revenue, or another agreed outcome—not clicks alone.
