# Visual artifacts

## Start with a concept, not a format

Define audience, purpose, viewing context, message, emotional register, and one visual idea. Decide what must be recognized immediately and what can reward longer inspection. The medium—logo, banner, GIF, canvas, social image, or generated artwork—then constrains how that idea is expressed.

## Build a visual system

Choose a restrained vocabulary of composition, color roles, typography, imagery, texture, and repeated motifs. For a brand family, show how the identity behaves across representative applications instead of presenting a logo in isolation. Use mockups to demonstrate rules, not to conceal weak source artwork.

## Handle reference material

Distinguish direct-use assets, style references, and conceptual inspiration. Preserve authorized assets faithfully. Extract relationships—contrast, rhythm, geometry, material, motion—rather than copying distinctive protected expression. Keep generated variants consistent with the same visual thesis.

## Design motion and algorithmic work

For animation, define duration, loop, frame rate, dimensions, file-size budget, and the action's anticipation, motion, and settling. For algorithmic art, define deterministic seed behavior, controllable parameters, bounds, and export. Reproducibility should coexist with meaningful variation.

## Validate the actual output

Render at delivery size and inspect legibility, cropping, color, edges, timing, looping, compression, and platform limits. For interactive generative work, exercise every control and verify same-seed reproduction. For multi-asset systems, review the set together for consistency and unintended repetition.
