# Game audio

## Give sound a role

Classify each sound as state feedback, spatial information, rhythm, atmosphere, narrative, reward, or masking. Important gameplay information needs a clear place in the mix and a non-audio alternative when accessibility requires it.

## Design variation

Use controlled variation in sample, pitch, timing, envelope, and layering to prevent repetition without obscuring recognition. Define concurrency limits and priority so frequent events do not overwhelm critical cues.

## Build adaptive systems

Drive music and ambience from stable game states with transitions that can recover from rapid changes. Separate musical intensity from every momentary event. Test transitions, loops, pause/resume, and save/load boundaries.

## Mix in context

Establish buses, loudness targets, ducking, spatial attenuation, and dynamic range for the target device. Test on speakers and headphones under dense gameplay, not only as isolated assets. Profile decode, streaming, voice count, and memory cost.
