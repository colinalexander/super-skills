# Brainstorming

## Set the search space

Clarify the objective, audience, constraints, and what would make an idea valuable. If these are uncertain, use a few contrasting interpretations rather than pausing immediately.

For collaborative design before implementation, first inspect any existing project context that can answer factual questions. Then refine purpose, constraints, and success criteria conversationally; use one question at a time when the user requests an interactive session. Surface an oversized scope early and decompose it before polishing details.

## Diverge before converging

Generate options across distinct mechanisms or strategic positions, not cosmetic variations. Include at least one conservative, one high-upside, and one reframing option when appropriate. Defer detailed criticism until a useful range exists.

## Make ideas comparable

Describe each candidate's premise, why it might work, principal risk, and cheapest informative test. Combine compatible strengths; do not average incompatible ideas into vagueness.

## Converge explicitly

Choose or rank options against the stated criteria. Identify what evidence would change the recommendation. End with a concrete experiment, decision, or next design question.

When the requested outcome is a design or specification, present the selected approach in sections proportional to complexity and resolve contradictions before implementation. Obtain approval when the user asked for a design gate; do not impose a mandatory document, commit, or planning ritual on every small creative task.
