# Capability discovery

## Search from the job

Describe the desired outcome, environment, constraints, and side effects before searching for a skill or plugin. Match capability and trust requirements, not only keywords.

## Evaluate candidates

Inspect the source, maintainership, license, dependencies, permissions, data handling, update history, and actual instructions. Prefer a narrower, inspectable capability over a broad bundle with unnecessary access.

Check whether the candidate's trigger overlaps existing skills and whether its workflow conflicts with repository or user rules.

## Install deliberately

Explain what will be installed and why. Use the supported installation path. Do not silently execute bundled scripts or grant credentials. Validate the installed structure and test a representative request plus a non-trigger.

## Fall back safely

If no suitable capability exists, perform the task with general tools when practical or propose a small new skill. Do not install an adjacent capability and represent it as an exact match.
