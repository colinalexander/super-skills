# Demonstration contract

Every focused example must make the following inspectable:

1. **Trigger:** why the named skill owns the task.
2. **Non-trigger:** a nearby request the skill should not absorb.
3. **Starting state:** the exact fixture or evidence available to the agent.
4. **Authority:** which files or external states may be changed.
5. **Expected decisions:** the reasoning commitments that distinguish the skill from generic task completion.
6. **Artifact:** an output that a reader can inspect or run.
7. **Verification:** evidence appropriate to that artifact.
8. **Limit:** what the example does not establish.

Reference artifacts are independently authored illustrations of the contract. They are not model outputs and must not be reported as benchmark results.
