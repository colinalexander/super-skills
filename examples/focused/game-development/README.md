# Game development: Signal Sprint

`fixture/signal-sprint.html` is a playable browser microgame. The player moves a cursor to collect green signals while avoiding red interference for 30 seconds.

- **Trigger:** the repeated decision loop, feedback, difficulty, input, and play evidence are central.
- **Non-trigger:** an ordinary dashboard with points does not become a game-development task.
- **Reference artifact:** [`reference-output/tuning-plan.md`](reference-output/tuning-plan.md).
- **Verification:** play the fixture with keyboard input, record whether the goal is understood without coaching, and report observed behavior separately from design intent.
