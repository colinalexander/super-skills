# Reference tuning plan

**Loop:** Read the field, choose a path, collect a signal, and recover from interference within a 30-second score chase.

1. Observe three first plays without coaching: whether the goal is understood, first-signal time, collisions, and final score.
2. Make collision feedback explicit with a brief visual/audio event and short invulnerability window rather than silent teleportation.
3. Introduce difficulty only after the base loop is understood—for example, measured hazard motion after the first three signals.
4. Add pause and visible restart controls; retain keyboard support and respect reduced-motion preferences.
5. Re-test comprehension and score distribution before adding progression or content.

This plan is an illustrative artifact, not recorded playtest evidence.
