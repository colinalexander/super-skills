# Expected decisions

- Preserve the sober operational identity while defining one explicit visual thesis.
- Make late or blocked deliveries and their causes dominate the hierarchy.
- Separate structure from decoration; improve layout, semantics, and states before surface styling.
- Use a small token vocabulary and repeat components only where behavior repeats.
- Provide non-color status cues, visible focus, usable touch targets, and responsive table behavior.
- Add or document loading, empty, error, and long-content states.
- Render representative desktop and narrow widths before claiming completion.
