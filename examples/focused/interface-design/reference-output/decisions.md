# Reference decisions

**Direction:** A restrained control-room interface that prioritizes exceptions and causes over aggregate decoration.

- Use neutral surfaces and reserve high-chroma color for operational exceptions.
- Pair every status color with text and a stable icon or shape.
- Put late and blocked work first, with cause and next action visible without opening a row.
- Collapse summary cards into a compact strip on narrow screens and convert the table into labeled records rather than horizontal overflow.
- Define focus, hover, selected, loading, empty, and error states from the same token vocabulary.

This record illustrates the decision contract. A completed run must still provide rendered evidence.
