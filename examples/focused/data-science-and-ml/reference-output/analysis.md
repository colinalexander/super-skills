# Reference analysis

The reported 98.7% random-split accuracy is not credible production evidence.

## Decision contract

At each week end, rank active accounts for a team that can contact 200. The outcome is closure within the following 30 days. False positives consume limited outreach; false negatives miss potentially preventable churn.

## Leakage

`cancellation_reason` and `closed_account_at` are generated by or after the outcome. `support_tickets_next_30d` occurs after prediction time. All must be excluded. Repeated account-month rows also allow the same account to cross a random split.

## Validation redesign

Train on earlier account cohorts and evaluate on a later untouched period using only features available by each prediction timestamp. Preserve account grouping where overlapping rows would leak identity. Compare with the base rate and a simple recent-usage rule.

Report precision among the top 200, recall at that capacity, calibration, incremental lift, and errors by plan, tenure, and relevant customer slices. Evaluate whether outreach changes outcomes before treating ranking quality as retention value.

Monitor feature availability, score distribution, calibration, segment performance, and intervention capacity; retain a simple fallback and a retirement condition if lift or data validity degrades.
